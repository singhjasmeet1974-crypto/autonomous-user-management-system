System Architecture & Security Engineering

Architectural design and defensive shell scripting paradigms implemented for Guru Nanak Dev Engineering College, Ludhiana.

🏗️ High-Level Architectural Flow

1
Pre-Flight & Privilege Verification

Inspects $EUID == 0. Blocks unprivileged execution with sudo advice; enables --dry-run simulation.

2
Input Validation Layer

POSIX regex ^[a-z_][a-z0-9_-]*$. Strips colons from GECOS comments to prevent /etc/passwd field desynchronization.

3
Core Provisioning & RBAC

Creates users with home directories; appends groups using usermod -aG preserving existing memberships.

4
Password Security Policies

Configures password expiration via chage. Prompts forced reset on first login (chage -d 0).

5
Defensive Deprovisioning

Shields root/operator accounts. Generates verified tar.gz backup before deletion; requires token DELETE <user>.

6
Compliance & Audit Logging

Writes structured entries to /var/log/sys_user_mgmt.log (chmod 0600) and broadcasts to syslog via logger.

🛡️ Security Threat Model & Safeguards

Security Threat Mitigation in Shell Script
Command Injection Strict POSIX regex input validation; all variables properly double-quoted.
Credential Leakage Zero plaintext passwords in arguments or logs; delegates to PAM passwd.
Accidental Root Deletion Hardcoded access control checks protect UID 0, system daemons, and $SUDO_USER.
Corrupt Data Deletion Validates backup archive with tar -tzf before invoking userdel -r.
Group Overwrite Uses usermod -aG instead of usermod -G to preserve prior groups.

▲ Deploying this Web App to Vercel

Ready

This interactive web app is ready for Vercel deployment with zero build steps.

Method 1: Deploy with Vercel CLI

npm i -g vercel
vercel

Accept default settings; Vercel will detect vercel.json and publish your site instantly.

Method 2: Deploy via GitHub (Recommended for College)

  1. Push your repository to GitHub:
    git push origin main
  2. Go to vercel.com and sign in with GitHub.
  3. Click "Add New..." → "Project" and select this repository.
  4. Click "Deploy". You will receive a live URL: https://your-project.vercel.app.

🐧 Running the Real Bash Script on Linux Server

Production

To execute genuine Linux system calls (useradd, usermod, chage) with root privileges:

On Ubuntu / Debian Server / AWS EC2 / DigitalOcean:

# 1. Clone repository
git clone <your-repo-url>
cd "Autonomous user management System"

# 2. Grant execution permission
chmod +x user_management.sh tests/*.sh

# 3. Launch with root privileges
sudo ./user_management.sh

Why Vercel Hosts the Showcase While Linux Hosts the Real Script:

Vercel is a serverless static web platform without persistent root privileges or /etc/passwd files. This web simulator serves as the presentation dashboard on Vercel, while the native user_management.sh runs directly on enterprise Linux servers.
